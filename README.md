# Vigilancia epidemiológica del dengue - Ica

Aplicación web en Streamlit para visualizar la tendencia, la incidencia por distrito y el perfil por edad y sexo de casos de dengue.

**Los datos son simulados con fines educativos y no son estadísticas oficiales.**

## Ejecutar en local

```
pip install -r requirements.txt
python -m streamlit run app_dengue.py
```

## Datos propios

Desde la barra lateral se puede cargar un CSV con las columnas: Fecha, Distrito, Poblacion, Casos.
